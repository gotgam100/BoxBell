# BoxBell 개발 및 업데이트 정리

> 문서 기준일: 2026-10-03  
> 저장소: `gotgam100/BoxBell`  
> 현재 개발 버전: `3.0` (빌드 `1`)

## 1. 프로젝트 개요

BoxBell은 복싱, 킥복싱, MMA 및 인터벌 운동을 위한 간단한 라운드 타이머 앱이다. 복잡한 운동 기록이나 계정 기능보다 실제 체육관에서 바로 사용할 수 있는 큰 타이머, 명확한 상태 표시, 실제 복싱 벨 소리에 집중한다.

- iPhone 최소 지원 버전: iOS 17.0
- 기본 언어: 한국어
- 지원 언어: 한국어, 영어
- 앱 번들 ID: `com.baekmac.boxbell`
- 개발 방식: SwiftUI, MVVM 형태의 상태 관리

## 2. 핵심 기능

### 타이머

- 라운드 시간: 2분, 3분 또는 직접 설정(최대 60분)
- 라운드 수: 1~12라운드 또는 무제한
- 휴식 시간: 30초, 60초 또는 직접 설정(10초~10분, 10초 단위)
- 준비 카운트다운: 0초, 5초 또는 10초
- 모드 A·B·C: 라운드 수, 라운드 시간, 휴식 시간, 준비 카운트다운을 모드별로 기기에 저장하고 불러옴
- 모드 기본값: A(3라운드, 3분, 휴식 30초, 준비 5초), B(6라운드, 5분, 휴식 60초, 준비 10초), C(12라운드, 10분, 휴식 2분, 준비 10초)
- 설정을 바꾸면 현재 선택된 모드에 즉시 저장되며, 앱을 다시 실행해도 마지막으로 선택한 모드가 유지됨
- 설정 화면에서 모드를 길게 눌러 이름 변경(최대 20자, 비우면 기본 이름). 메인 화면에도 반영되며 긴 이름은 `…`로 표시
- '모드 초기화' 버튼: 확인 팝업 후 모든 모드 이름·설정과 선택 모드를 첫 설치 상태로 되돌림
- 마지막 라운드가 끝나면 추가 휴식 없이 최초 상태로 복귀
- 타이머 진행 중에는 모드, 라운드 수, 라운드 시간, 휴식 시간 및 준비 시간을 변경할 수 없음
- 일시정지 기능 없음

### 벨과 화면 효과

- 라운드 시작과 종료: `bell_start_end.wav`
- 라운드 종료 30초 전: `bell_30_seconds.wav`
- 준비 카운트다운: 남은 초마다 `countdown_beep.wav`(880Hz 0.16초 비프음, 앱이 화면에 있을 때만)
- 30초 전부터 라운드 종료까지 원형 게이지 점멸
- 벨이 울릴 때 디지털 숫자 좌우 흔들림
- 준비 카운트다운: 흰색 숫자, 흰색 원형 게이지, `준 비` 또는 `READY` 표시
- 라운드: 빨간색 타이머 및 게이지
- 휴식: 초록색 타이머 및 게이지

### 조작

- 중앙의 붉은 벨을 탭하면 즉시 시작
- 진행 중 붉은 벨을 탭하면 초기화
- 탭 시 눌림 애니메이션과 햅틱 제공
- 초기 상태는 `0 / 전체 라운드`, 진행 후에는 현재 라운드 표시
- 무제한은 `현재 라운드 / 무제한`으로 표시

## 3. 타이머 진행 구조

```text
최초 상태
  -> 준비 카운트다운(0초이면 생략)
  -> 1라운드
  -> 휴식
  -> 다음 라운드
  -> ...
  -> 마지막 라운드
  -> 최초 상태
```

준비 카운트다운은 전체 운동을 처음 시작할 때 한 번만 실행한다. 각 라운드 사이에는 설정된 휴식만 적용하며 마지막 라운드 뒤에는 휴식이 추가되지 않는다.

타이머는 단순히 1초씩 차감하지 않고 종료 시각을 기준으로 남은 시간을 다시 계산한다. 앱이 잠시 비활성화되거나 시스템 타이머 호출이 늦어져도 실제 시각과의 오차를 줄이는 구조다.

## 4. 화면과 디자인

- 상단: `BOXBELL` 제목, 라운드 진행 표시, 설정 버튼
- 중앙: 붉은 벨 이미지와 원형 진행 게이지
- 하단: DS-Digital Bold 폰트를 사용한 대형 디지털 타이머
- 설정 영역(두 칸)
  - 위 칸: '모드' 라벨과 모드 버튼 3개(모드 이름 16pt)
  - 아래 칸: 원형 휠 버튼 4개(라운드 수, 라운드 시간, 휴식 시간, 준비 카운트다운). 아래로 내리면 값 증가, 위로 올리면 감소, 한 칸마다 중간 세기 햅틱
  - 표시 단위: 라운드는 횟수(12 다음 ∞), 라운드 시간은 분(`3`), 휴식·카운트는 초 앞에 '.'(`.30`, `.5`)
  - 아래에 작은 글씨(라운드/라운드 시간/휴식/카운트)로 의미를 표시
- 휴식 중에는 상단 라운드 표시 옆에 초록색 '휴식중' 표시
- 화면 높이 700pt 미만(iPhone SE 등)에서는 벨·숫자·간격을 줄인 압축 레이아웃 사용
- 가장 아래: 시작 방법과 설정 잠금 안내
- 앱 아이콘과 화면용 벨 이미지는 Asset Catalog에서 관리
- iPhone 레이아웃은 기존 디자인을 유지
- iPad 또는 iPhone 호환 모드에서는 별도 축소 레이아웃과 세로 스크롤을 사용해 잘림을 방지
- iPad는 상하 반전을 포함한 모든 화면 방향을 선언하고, iPhone은 세로 방향 사용

## 5. 오디오 및 백그라운드 동작

### 앱이 화면에 열려 있을 때

- `AVAudioPlayer`로 벨 소리를 재생한다.
- 다른 음악이나 영상 소리와 함께 재생되도록 오디오 세션을 구성한다.
- 벨 재생이 끝나면 오디오 세션을 비활성화해 기존 미디어 재생이 자연스럽게 이어지도록 한다.
- 백그라운드에서 이미 지난 벨은 앱에 돌아왔을 때 뒤늦게 재생하지 않는다.

### 앱이 백그라운드에 있을 때

- `UNUserNotificationCenter`를 이용해 남은 라운드 일정의 1회성 로컬 알림을 미리 예약한다.
- 앱으로 돌아오거나 타이머를 초기화하면 BoxBell이 생성한 알림만 취소한다.
- AlarmKit, ActivityKit, Live Activity 및 홈 화면 위젯은 현재 사용하지 않는다.
- 과거 AlarmKit 사용 중 발생했던 다이내믹 아일랜드 잔상과 종료되지 않은 시스템 알람 문제를 피하기 위해 현재 구조로 변경했다.

## 6. 화면 자동 잠금 정책

버전 3.0에서 운동 중 화면 유지 기능을 기본 동작으로 추가했다.

- 준비, 라운드 또는 휴식이 진행 중이고 앱이 화면에 있을 때: 자동 잠금 방지
- 타이머 종료 또는 초기 상태: 자동 잠금 허용
- 앱이 백그라운드로 이동했을 때: 자동 잠금 허용
- 저전력 모드일 때: 사용자의 배터리 절약 설정을 존중해 자동 잠금 허용
- 저전력 모드를 끄고 앱으로 돌아오면 진행 상태에 맞게 다시 적용

구현은 `UIApplication.shared.isIdleTimerDisabled`와 앱 활성 상태, 타이머 실행 상태, 저전력 모드 상태를 함께 확인한다.

## 7. 설정 및 다국어

설정 화면은 다음 항목을 제공한다.

- 언어: 한국어, English
- 모드: A, B, C (길게 눌러 이름변경)
- 라운드 설정: 붉은 슬라이더를 드래그해 1~12라운드 또는 무제한 선택
- 라운드 시간 설정: 2분, 3분, 직접 설정
- 휴식 시간 설정: 30초, 60초, 직접 설정
- 준비 카운트다운: 0초, 5초, 10초
- 앱 버전
- 이용약관 및 정책
- 개발자의 다른 앱

## 9. 주요 문제 해결 내역

### 타이머 정확도

- 앱 화면과 백그라운드 알림 시간이 달라지던 문제를 종료 시각 기반 계산으로 개선
- 설정 버튼이나 컨트롤 조작 중에도 시간이 계속 흐르도록 수정
- 백그라운드에서 이미 지난 벨이 복귀 후 재생되는 문제 수정
- 마지막 라운드 후 불필요한 휴식이 추가되던 흐름 수정

### 알림과 다이내믹 아일랜드

- AlarmKit 알람을 사용하던 과정에서 알람 종료 후 다이내믹 아일랜드 표시가 남는 현상을 조사
- 앱 종료 후에도 시스템 알람이 반복되거나 잔상이 유지될 수 있는 구조 제거
- 위젯 및 Live Activity 타깃 제거
- 현재는 1회성 로컬 알림 방식으로 단순화

### 오디오

- 앱 실행만으로 기존 음악이 중단되거나 음량이 낮아지던 문제 수정
- 벨이 필요할 때만 오디오 세션을 활성화하고 종료 후 해제
- 다른 미디어와 함께 재생할 수 있도록 `mixWithOthers` 적용

### 화면 및 심사 대응

- iPad Air 심사 중 상하단 잘림과 스크롤 불가 문제 대응
- iPhone 디자인은 유지하고 iPad에만 별도 크기와 간격 적용
- 작은 화면에서도 전체 내용을 확인할 수 있도록 iPad 레이아웃에 스크롤 적용
- 벨 이미지와 원형 게이지의 겹침, 정렬 및 크기 반복 조정
- 디지털 폰트 등록과 크기 조정

## 12. 빌드 및 테스트

### Xcode에서 실행

1. `Boxbell.xcodeproj`를 연다.
2. `Boxbell` 스킴을 선택한다.
3. Signing Team이 올바른 개발자 계정인지 확인한다.

### 확인할 항목

- 준비 카운트다운은 최초 시작 시 한 번만 나타나는가
- 라운드, 휴식, 마지막 라운드 종료 순서가 정확한가
- 30초 전 벨과 점멸이 정상인가
- 백그라운드 알림이 한 번만 울리는가
- 앱 복귀 시 지난 벨이 다시 재생되지 않는가
- 음악 재생 중 벨이 함께 들리고 기존 미디어가 정상적으로 이어지는가
- 일반 모드에서 운동 중 화면이 잠기지 않는가
- 저전력 모드와 백그라운드에서 자동 잠금이 다시 허용되는가

iPhone 기기용 빌드를 우선 확인한다. 로컬 테스트 환경에서는 Xcode와 CoreSimulator 구성 버전 차이로 시뮬레이터 사용에 제한이 있어 실제 기기 테스트를 우선한다.

## 13. 현재 작업 상태

버전 3.0은 화면 자동 잠금 방지와 모드 저장 기능을 포함하며 Apple Watch 기능은 제외했다. 배포 전에는 다음 순서가 필요하다.

1. 실제 iPhone에서 화면 자동 잠금 정책 확인
2. Archive 및 App Store 배포 서명 확인
3. App Store 설명과 스크린샷에 Apple Watch 언급이 없는지 점검
4. 최종 커밋 및 GitHub 푸시
